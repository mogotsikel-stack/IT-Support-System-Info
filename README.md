## IT-Support-System-Info
IT Connect is a lightweight desktop application designed to help resolvers & end users quickly access key device and user information. 

Once launched, the app places a small icon on the top-right side of the desktop. 

A single click reveals an information overlay containing critical details that enable faster troubleshooting and improved customer experience.

The overlay automatically disappears when the cursor moves away from the frame, ensuring it remains discreet while still being readily accessible.
